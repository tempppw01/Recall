# v0.2 任务清单

> 当前阶段：v0.2 主闭环已打通。物品管理已具备本地编辑、任务联动、远端同步，以及基于任务完成的状态/数量回写。

## 进度

- 完成度：**8/8**
- 当前状态：**基本完成（物品管理已形成可用闭环）**

## 任务列表

### A) 页面结构与视觉收敛

- ⬜ 左侧导航层级优化  
  DoD：导航分区、图标、计数、选中态更清晰。
- ⬜ 页面 Header 重构  
  DoD：标题、说明、快捷操作结构统一。
- ⬜ 主内容区骨架优化  
  DoD：Header / Summary / Controls / Content 层级稳定。
- ⬜ 深色主题统一  
  DoD：背景、边框、文本、浮层层级一致。

### B) 物品管理功能

- ✅ 建立物品数据模型  
  DoD：支持名称、分类、标签、位置、数量、状态、备注等基础字段。
- ✅ 完成物品列表与筛选  
  DoD：支持搜索、分类筛选、位置筛选、状态筛选。
- ✅ 完成物品编辑与状态流转  
  DoD：支持新增、编辑、删除、状态切换（正常 / 库存低 / 待补货 / 缺失）等可用操作。
- ✅ 打通物品与任务联动（首版）  
  DoD：可从物品生成“购买 / 补货 / 归位”任务。
- ✅ 完成任务后回写物品状态（首版）  
  DoD：完成关联任务后，物品状态可自动回到 `normal`；后续再补更细粒度规则。
- ✅ 远端同步 / API 接入  
  DoD：物品数据具备持久化同步能力，不只停留在本地 `itemStore`。
