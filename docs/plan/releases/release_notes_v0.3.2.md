# Release Notes — v0.3.2

这是一个体验修复版本，重点处理 AI 助手的待办决策落地、浅色模式视觉问题，以及 AI 面板的信息密度。

## 主要改进

### AI 助手
- 记录助手会先参考当前计划状态，再决定新增、修改、删除、复用、跳过或阻塞。
- 修复 AI 返回修改/删除建议后，前端没有展示可应用操作的问题。
- 新增待办改为即时写入本地任务库，并同步到 PG，减少“看起来添加了但实际没有落地”的错觉。
- 记录助手不再因为角色限制而拒绝普通信息类问题；只有需要改动计划时才生成待办决策。
- 移除 AI 面板里的 `todo-agent` 标识和新手提示说明，让界面更干净。

### 视觉与主题
- 修复浅色模式下部分区域出现黑色块的问题。
- 调整 AI 页顶部说明文案，避免标题和辅助说明重复占位。

## 验证
